# 选关与模式演示初版

> 本文保留交互演示阶段的设计记录。当前两种新模式已升级为可通关关卡，规则、操作和解法见 [可通关关卡设计](playable-levels.md)。下文的“尚未接入通关”和演示按钮说明不代表当前版本。

本轮按“先做界面和交互演示”实现。经典关卡可正常游玩；定时变化和莫比乌斯环是独立演示页面，页面明确标注演示用途，尚未接入完整推箱规则、通关判定和进度存档。

## 入口与返回

| 页面 | 路由 | 可用操作 |
| --- | --- | --- |
| 选关 | `/pages/select` | 默认启动页，进入经典、定时变化、莫比乌斯环 |
| 经典 | `/pages/levels/level01` | 保留原有玩法；点击标题或系统返回进入选关 |
| 胜利 | `/pages/win` | 重玩经典关卡、返回选关；系统返回进入选关 |
| 定时变化 | `/pages/timed` | 暂停/继续、手动翻色、重置、返回 |
| 莫比乌斯环 | `/pages/mobius` | 转动、前进、展开/环视图、返回 |

页面之间使用 `router.replace`，反复查看演示不会增加页面栈。

## 定时变化演示

- 5×5 地图，每 8 秒在 A/B 两个状态间翻转蓝框地形；角色、箱子及其他格子保持原位。
- 手动翻色后重新从 8 秒倒计时，保留暂停状态；重置回到 A 地图并继续计时。
- 每次只保留一个一秒定时器。暂停、页面隐藏、返回、销毁都会停止计时；重新显示时从剩余秒数继续，不补算后台时间。
- 倒计时只更新文字和进度条，地形变化时原地更新格子颜色。

## 莫比乌斯环演示

- 12 列、5 行的条带，左右边缘相接，穿过接缝时行号变为 `4 - y`；走一圈上下翻转，走两圈回到原行。
- 红点初始位于第 1 行、第 11 列，点击两次“前进”即可观察它从上方右侧跨到下方左侧。
- 环视图与展开图共用同一位置数据。“转动”改变观察角度，不改变红点所处格子；“展开”只切换显示方式。
- 环带使用带半扭转的三维参数曲面投影到二维，按深度绘制黑白格。12 个视角在开发时生成为 168×168 透明 PNG，设备只在点击时切换图片，不持续运行动画或使用 WebGL/canvas。
- 投影和接缝坐标定义在 `src/demos/mobiusGeometry.js`；离线生成器复用同一份几何计算，红点位置与投影视角保持一致。

## 素材与重新生成

标题和按钮复用 Ark Pixel 单字。补充“变化前进动”5 个字的原字体字模，源素材库共 66 个字符。原图保留 48×48；运行时字图继续使用 56×56 透明安全留白和 `object-fit: contain`，避免底部笔画裁切。

```sh
node scripts/generate-glyphs.cjs
npm run assets:sync
npm run assets:mobius
npm test
npm run lint
npm run build
```

无需安装系统字体或联网。新页面沿用 192×490 / 212×520 的宽高适配和圆弧安全区。模拟器结果及截图见 `docs/verification/README.md`；尚未进行真机功耗和内存测量。
